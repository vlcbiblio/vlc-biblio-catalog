# VLC Biblio catalog instructions

- Follow `PUBLISH.md` for every public-site deployment.
- For any event-related change, read and follow `EVENTS_GUIDE.md` before editing.
- Public event pages may contain only channel, club, organization, or project
  contacts. Never publish a private person's account, phone number, or email
  unless the user explicitly authorizes that exact contact for that event.
- Run only the tests relevant to the files changed and verify GitHub Pages before
  reporting that the public site was updated.
